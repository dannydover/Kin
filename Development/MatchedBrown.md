# Matched Brown

Kin uses a dark brown vertical backdrop and warm grouped surfaces. Color assets
set text, accent, field, and border colors. `KinTheme` adds the shared gradients,
circle artwork, and typography. Libre Baskerville Bold comes from the typeface
used in the app icon. Its license is bundled with the font.

- The index uses rounded family cards, a centered Kin title, and native search.
  The primary name leads. Partner names sit beneath it. Up to four child
  previews sit on a separate grid, with smaller circles and prominent ages.
  Child initials use soft pink for female, powder blue for male, and the
  original cream for unspecified or other gender. Adults keep clay.
- Profiles group identity, partners, children, parents, and notes. Relationship
  edit buttons have a pencil and an accessible label identifying the person.
- Edit person, add person, and relationship flows use native modal sheets.
  Native forms, toggles, date selection, contact selection, and confirmation
  controls keep their standard behavior. Kin-owned screens use the shared theme.
- Dynamic Type allows the child grid to become a single column. Full names and
  profile facts wrap, and the relationship edit target scales with text size.
